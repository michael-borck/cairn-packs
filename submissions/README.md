# Submissions

No submissions yet.

Add one folder per pack:

```text
submissions/<pack-id>/
├── pack.learnpack
└── submission.json
```

Copy [`../templates/submission.json`](../templates/submission.json), fill it in, and run:

```bash
npm run validate
```

Then open a pull request. A merged submission is not live until the maintainer rebuilds and deploys the catalog.
